\# Warkopolo



Sistem e-order dan manajemen restoran full-stack, lanjutan dari proyek ORDHE.

Terdiri dari customer app, kasir app, dan backend API dengan database MySQL.



\## Fitur



\- Customer: lihat menu, checkout, booking meja

\- Kasir: kelola menu (CRUD), kelola order, kelola status meja



\## Tech Stack



\- Frontend: React (Vite)

\- Backend: Express.js

\- Database: MySQL



\## Struktur Proyek



\- `customer-app/` — aplikasi untuk pelanggan

\- `kasir-app/` — dashboard untuk kasir

\- `backend/` — REST API

\- `database/` — skema database



\## Cara Menjalankan



1\. Import `database/schema.sql` ke MySQL

2\. `cd backend \&\& npm install \&\& npm start`

3\. `cd customer-app \&\& npm install \&\& npm run dev`

4\. `cd kasir-app \&\& npm install \&\& npm run dev`
